# Video Downloader

Firefox 用の動画ダウンロード拡張機能です。

## 構成

- `normal/`
  - MP4、WebM などの直接動画 URL に対応
- `HLS/`
  - 直接動画 URL に加えて、HLS の `.m3u8` に対応

## 主な機能

- ページ内の動画 URL を検出
- 動画候補の一覧表示
- 設定画面による一覧の絞り込み（サイズ・拡張子）
- ファイルサイズの取得・表示
- ページタイトルを基準にしたファイル名
- Firefox のダウンロード機能による保存
- ダウンロード開始時に一覧を自動的に閉じる
- 外部配信元への Referer を考慮した取得
- HLS プレイリストとセグメントの保存試行

## 導入方法

### 開発・動作確認用（一時的な導入）

この方法は開発中の確認用です。Firefoxを終了すると、次回起動時には拡張機能が解除されます。

1. Firefox で `about:debugging` を開く
2. 「この Firefox」を選択
3. 「一時的なアドオンを読み込む」をクリック
4. 使用するフォルダー内の `manifest.json` を選択
   - 通常版: `normal/manifest.json`
   - HLS 版: `HLS/manifest.json`
5. 対象ページを再読み込みする

### 継続利用する場合

Firefoxを再起動した後も使用するには、拡張機能を署名済みのXPIファイルとしてインストールする必要があります。通常はMozilla Add-ons（AMO）で署名を受けてからインストールします。

Firefox Developer EditionやNightlyでは、署名検証を無効にしてローカルで継続利用できる場合があります。ただし、これは開発用の設定であり、通常版Firefoxでは利用できません。

## 使用方法

1. 動画があるページを開く
2. 拡張機能のアイコンをクリックする
3. 動画候補から「ダウンロード」または「HLS 保存」をクリックする
4. 保存ダイアログで保存先を選択する

ダウンロードボタンを押すと一覧画面は閉じます。ダウンロードに失敗した場合、現在の一覧画面には失敗理由は表示されません。

## 設定画面

一覧に表示する条件は設定画面から変更できます。値は拡張機能のローカルストレージへ保存されるため、
アドオンを再読み込みしても保持されます。

### 開き方

- 動画候補の一覧にある「設定」ボタン
- `about:addons` の対象アドオンにある「設定」タブ

### 設定項目

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| このサイズ以下の動画を一覧に出さない | 1 MB | 指定したサイズ以下の候補を一覧から除外します。`0` にするとサイズで絞り込みません。 |
| サイズが取得できない候補の扱い | 動画・音声の拡張子を持つものだけ表示する | サイズ不明の候補をどう扱うかを選びます。 |
| 動画・音声として扱う拡張子 | mp4, webm, m4v, mov, m3u8 など | 一覧に載せる拡張子をカンマ区切りで指定します。 |
| 一覧に出さない拡張子 | js, mjs, css, html など | 動画以外の URL を候補から外します。 |
| 一覧に出さない URL キーワード | 空 | URL に含まれる語で候補を除外します（任意）。 |
| サイズが取得できない場合の最終手段 | 行わない | ダウンロードを伴う最終手段を使うかどうかを選びます。 |
| 一覧にサイズの取得方法を表示する | オフ | サイズの取得元（HEAD / Range など）を一覧に併記します。 |

設定の変更は、次に一覧を開いたときから反映されます。

## 権限とプライバシー

- ページ内の動画URLを検出するため、すべてのページへのアクセス権を使用します。
- 動画の保存にFirefoxのダウンロード機能を使用します。
- サイズ確認やReferer対応のため、検出した動画URLへアクセスする場合があります。
- 利用状況、ページ情報、動画URLを作者のサーバーへ送信する処理はありません。
- 本リポジトリのソースコードを確認したうえで利用できます。

## サイズ表示について

ファイルサイズは、追加の通信が少ない順に次の手段で取得します。

1. ページが実際に受信したサイズ（Performance API。追加通信なし）
2. 保存履歴にある同一 URL のサイズ（追加通信なし）
3. ページの通信で観測した応答ヘッダーの `Content-Length` / `Content-Range`（追加通信なし）
4. 過去に取得して保存したサイズ（追加通信なし）
5. `HEAD` 応答の `Content-Length`
6. `Range: bytes=0-0` 応答の `Content-Range`

Range 非対応の配信元が 200 応答で `Content-Length` を返す場合も、その値を使います。
いずれの場合も応答本文は受信せずに破棄するため、サイズ確認だけを目的としたダウンロードは発生しません。

上記で分からない場合は、既定ではサイズを「不明」と表示します。
本文を取得してバイト数を数える手段は、設定画面の「サイズが取得できない場合の最終手段」で
明示的に選んだ場合のみ実行します（初期値は「行わない」）。

「ダウンロード機能で確認する」を選んだ場合は、サイズが分かった時点で中止し、
`cancel` → 状態の確定待ち → `removeFile` → `erase` の順で、ファイルとダウンロード履歴の両方を削除します。
ただし、確認を開始してから削除するまでの間に、Firefox のダウンロード表示へ一瞬現れることがあります。
また「本文をすべて取得して数える」を選ぶと、本文を受信するため通信量が大きくなります。

配信元が `Content-Length` も `Content-Range` も返さない場合（チャンク転送など）は、
レスポンスが完了するまで総サイズが分からないため、サイズは「不明」となります。

また、署名付き URL、Range 配信、Cookie 制限、Referer 制限、ホスト権限が許可されていない場合などに、
サイズを取得できないことがあります。どの手段で取得したかは、設定画面の
「一覧にサイズの取得方法を表示する」を有効にすると一覧で確認できます。

サイズが不明でも、ダウンロード可能な場合はダウンロードを実行できます。

なお、設定画面の「このサイズ以下の動画を一覧に出さない」で指定したサイズ以下の候補は一覧に表示されません。
初期値は 1MB です。サイズが取得できない候補の扱いも、設定画面で選択できます。

## 対応できない場合

以下の動画は保存できない場合があります。

- DRM で保護された動画
- 暗号化されたストリーム
- 配信元がアクセスを拒否する動画
- 有効期限が切れた署名付き URL
- サーバー側で直接ダウンロードを禁止している動画
